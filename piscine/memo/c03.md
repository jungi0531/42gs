## strlcat 이란?

strcat 함수와 마찬가지로 dest의 뒤에 src 문자열을 덧붙이는 함수다.

그런데 strcat이 있는데 왜 또 strlcat이란 함수가 존재할까?

strcat
- 그냥 dest 뒤에 src 문자열을 붙이는 함수
- 이렇게 되면 dest 문자열의 크기가 src 문자열을 붙이기에 부족할 시에 문제가 발생한다.

strncat
- strcat과 비슷한 문제를 가지고 있지만, 붙이는 크기를 n만큼 지정해주기에? 쪼금? 더 안정적이라고 볼 수 있(나?)지만 또이또이다.

strlcat
- strcat과 하는 짓은 같으나 return 값이 다름
