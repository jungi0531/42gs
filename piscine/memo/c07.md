함수 파라미터로 오는 int **range는  int *(정수형 포인터)를 가리키는 포인터!
- 즉 함수 내에서 *range에다가 동적 할당을 하면 함수를 호출한 쪽에서도 할당된 배열을 사용할 수 있음!

호출한 쪽에서는 int *로 변수를 선언해놓고 인자로 넣을 때 &변수명으로 넣어서 int *를 가리키는 주소를 인자로 넣는다!

그러니까 *range(정수를 가리키는 포인터)에다가 배열로 할당을 하면 배열을 동적할당 가능하다!
