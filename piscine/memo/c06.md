# ex03

- 주어진 인자를  아스키 코드 순서로 정렬해서 출력
- argv[0] 제외 모두 출력
- 한 라인 당 한 인자

argv[]를 정렬하고 할까
```c
i = 1;
while (i < argc - 1)
{
    ii = i + 1;
    while (ii < argc)
    {
        if (strcmp(argv[i], argv[ii]) > 0)
        {
            swap(argv[i], argv[ii]);
        }   
        ii++;
    }
    i++;
}

```
