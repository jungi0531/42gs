## 00번

파일 3개
- main.c: rush 실행 시킬 메인 함수
- ft_putchar.c: c00 ex00 파일, char을 하나 write하는 함수
- rush00.c: 실제 코드 작성 파일

가로(width) x 길이 세로(length) y 길이의 네모 출력
- 모서리가 o
- 가로는 -
- 세로는 |

1.
-> width가 0이나 x - 1 && length가 0이나 y - 1이면 o

2.
-> width가 0이나 x - 1이면 o
-> length가 0이나 y - 1이면 o

3.
-> 둘다 모서리가 아니면 공백 출력

출력 조건문을 코드로 하면

```c
if (width == 0 || width == x - 1)
{
    if (length == 0 || length == y - 1)
        o 출력
    else
        | 출력
}
else
{
    if (length == 0 || length == y - 1)
        - 출력
    else
        공백 출력
}
```

그러니까 여기서 width와 length도 증가시키는 반복문도 추가하면

```c
while (length < y)
{
    // 한 층에서 반복할 반복문
    width = 0;
    while (width < x)
    {
        if (width == 0 || width == x - 1)
        {
            if (length == 0 || length = y - 1)
                ft_putchar('o');
            else
                ft_putchar('|');
        }
        else
        {
            if (length == 0 || length == y - 1)
                ft_putchar('-');
            else
                ft_putchar(' ');
        }
        width++;
    }
    length++;
}
```
